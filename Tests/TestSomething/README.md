# TestSomething

## 1. What is this?
A simple playground and debugging console application (targeting `net10.0`) used for running quick developer tests, debugging expression serialization logic, or testing specific compiler optimizations isolated from the main test suites.

## 2. How to use?
Run this console project using the .NET CLI:

```bash
dotnet run --project Tests/TestSomething/TestSomething.csproj
```
