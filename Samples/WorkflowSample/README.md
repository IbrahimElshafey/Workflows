# WorkflowSample

## 1. What is this?
An executable sample console application (targeting `net10.0`) demonstrating how to define, configure, register, and execute workflows using the workflows framework. It serves as an end-to-end playground and architectural reference for developer teams.

Demonstrated features:
- Defining custom workflows with complex command execution, signaling, and compensation steps.
- Configuring in-process execution hosts.
- Setting up command executors.
- Posting events and simulating external triggers.

## 2. How to use?
You can run this sample directly from your terminal using the .NET CLI.

### Run command:
```bash
dotnet run --project Samples/WorkflowSample/WorkflowSample.csproj
```
